## About

I build products end to end, with Rust at the core: compilers, encrypted storage and servers, and the native desktop and mobile clients around them. TypeScript, Swift and Kotlin cover the user-facing side where the product needs it. I work with predictable architecture, reproducible environments and documentation that matches the code. Every project below is public, and each README describes how to build and run it.
