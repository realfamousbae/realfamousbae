## Обо мне

Делаю продукты целиком: типизированные API и слои данных, кроссплатформенные десктопные приложения, мобильные клиенты и веб-интерфейсы, которые их связывают. Для меня важны предсказуемая архитектура, воспроизводимое окружение и честная документация. Каждый проект ниже можно склонировать и запустить так, как описано в его README.

## Избранные проекты

### [realfamousbae focus](https://github.com/realfamousbae/realfamousbae-focus)

<a href="https://focus.realfam0usbae.chatgpt.site"><img src="https://img.shields.io/badge/demo-live-2EA44F?style=flat-square" alt="Live demo" /></a>
<img src="https://img.shields.io/badge/license-MIT-blue?style=flat-square" alt="MIT" />

Приватные таймеры обратного отсчёта с синхронизацией между устройствами. Таймеры привязаны к вошедшему пользователю и хранятся в Cloudflare D1. Приложение импортирует файлы `.ics`/`.ical` и `.csv` из Google Календаря и корректно обрабатывает повторяющиеся события, исключения, дубликаты и часовые пояса. Интерфейс доступен на русском и английском.

`Next.js 16` · `React 19` · `TypeScript` · `Cloudflare Workers & D1` · `Drizzle ORM` · `Vite`

→ [Открыть сайт](https://focus.realfam0usbae.chatgpt.site)

### [Limita](https://github.com/realfamousbae/limita)

<a href="https://github.com/realfamousbae/limita/releases"><img src="https://img.shields.io/github/v/release/realfamousbae/limita?include_prereleases&style=flat-square&label=release" alt="Release" /></a>
<img src="https://img.shields.io/badge/macOS-14%2B-000?style=flat-square&logo=apple" alt="macOS 14+" />
<img src="https://img.shields.io/badge/status-pre--release-7C3AED?style=flat-square" alt="Pre-release" />

Нативное приложение для строки меню macOS, которое показывает лимиты Claude Code и Codex. Если подвести курсор к верхнему краю любого экрана, выезжает компактная плашка; область вокруг выреза под камеру остаётся свободной. Каждый сервис опрашивается по своему расписанию, а дашборд помечает устаревшие данные и показывает понятные ошибки. Учётные данные читаются из Keychain, но никогда не обновляются и не изменяются.

`Swift` · `SwiftUI` · `Keychain`

→ [Скачать DMG](https://github.com/realfamousbae/limita/releases)

### [Developer Profile API](https://github.com/realfamousbae/developer-profile-api)

<img src="https://img.shields.io/badge/API-GraphQL-E10098?style=flat-square&logo=graphql&logoColor=white" alt="GraphQL" />
<img src="https://img.shields.io/badge/setup-docker_compose_up-2496ED?style=flat-square&logo=docker&logoColor=white" alt="Docker" />

Read-only GraphQL-сервис на NestJS, собранный по продакшен-практикам. Слоем хранения поверх CockroachDB управляет Prisma. Одна команда `docker compose up` поднимает базу, дожидается её готовности, применяет миграции, выполняет идемпотентный сид и после этого запускает API.

`NestJS` · `GraphQL (Apollo)` · `Prisma` · `CockroachDB` · `Docker`

### [My Staff](https://github.com/realfamousbae/my-staff)

<a href="https://github.com/realfamousbae/my-staff/actions/workflows/verify.yml"><img src="https://github.com/realfamousbae/my-staff/actions/workflows/verify.yml/badge.svg" alt="Verify" /></a>
<a href="https://github.com/realfamousbae/my-staff/releases"><img src="https://img.shields.io/github/v/release/realfamousbae/my-staff?include_prereleases&style=flat-square&label=release" alt="Release" /></a>
<img src="https://img.shields.io/badge/status-active_development-d7ff70?style=flat-square&labelColor=171c16" alt="Active development" />

Local-first Android-приложение для коллекционеров: фотографии реальных предметов превращаются в личные коллекционные карточки. Оригиналы фото и база SQLite хранятся на устройстве. Синхронизация идёт через аккаунт на собственном бэкенде NestJS + PostgreSQL, а резервные копии выгружаются в переносимые ZIP-архивы. В модели данных личные экземпляры отделены от каталожных изданий.

`React Native` · `Expo` · `TypeScript` · `SQLite` · `NestJS` · `PostgreSQL`

→ [Попробовать APK](https://github.com/realfamousbae/my-staff/releases)

### [Hubble](https://github.com/realfamousbae/hubble)

<a href="https://github.com/realfamousbae/hubble/releases"><img src="https://img.shields.io/github/v/release/realfamousbae/hubble?style=flat-square&label=release" alt="Release" /></a>
<img src="https://img.shields.io/badge/platform-macOS_·_Windows_·_Linux-555?style=flat-square" alt="Cross-platform" />

Кроссплатформенное рабочее пространство, в котором веб-сервисы (Telegram, YouTube, Discord, музыка, ИИ-инструменты) работают как нативные плитки в одном окне. Версия 1.0 полностью переписана с Electron на Tauri 2 и использует системный webview вместо встроенного Chromium. Есть BSP-автотайлинг, изолированные постоянные сессии для каждого сервиса и управление медиа. Удалённые страницы не получают доступа к нативному IPC.

`Tauri 2` · `Rust` · `TypeScript` · `React`
