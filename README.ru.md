## Обо мне

Делаю продукты целиком: типизированные API и слои данных, кроссплатформенные десктопные приложения, мобильные клиенты и веб-интерфейсы, которые их связывают. ## Избранные проекты

### [Veil](https://github.com/realfamousbae/Veil)

Приватная карта мира на OpenStreetMap без аккаунтов, cookies и аналитики. Это статический сайт без бэкенда: векторная карта, поиск мест, офлайн-регионы, сохранённые места только на устройстве и устанавливаемое PWA со светлой, тёмной и бумажной темами. Правила приватности записаны как контракт и проверяются автоматическим тестом в CI при каждом изменении.

`Svelte` · `MapLibre` · `PMTiles` · `TypeScript` · `PWA`

→ [Открыть карту](https://veil-239.pages.dev)

### [Limita](https://github.com/realfamousbae/limita)

Нативное приложение для строки меню macOS и трея Windows, которое показывает лимиты Claude Code и Codex. Если подвести курсор к верхнему краю любого экрана, выезжает компактная плашка. Дашборд показывает 5-часовые и недельные лимиты, обратный отсчёт до сброса, балансы и причину, если обновление не удалось. Версия для macOS написана на Swift. В версии 0.3 появился порт для Windows на Tauri и Rust. Учётные данные только читаются и никогда не сохраняются и не обновляются.

`Swift` · `SwiftUI` · `Rust` · `Tauri` · `TypeScript`

→ [Скачать для macOS или Windows](https://github.com/realfamousbae/limita/releases)

### [realfamousbae focus](https://github.com/realfamousbae/realfamousbae-focus)

Приватные таймеры обратного отсчёта с синхронизацией между устройствами. Таймеры привязаны к вошедшему пользователю и хранятся в Cloudflare D1. Приложение импортирует файлы `.ics`/`.ical` и `.csv` из Google Календаря и корректно обрабатывает повторяющиеся события, исключения, дубликаты и часовые пояса. Интерфейс доступен на русском и английском.

`Next.js 16` · `React 19` · `TypeScript` · `Cloudflare Workers & D1` · `Drizzle ORM` · `Vite`

→ [Открыть сайт](https://focus.realfam0usbae.chatgpt.site)

### [Staya](https://github.com/realfamousbae/Staya)

Открытое приложение для iOS и Android, чтобы делиться геопозицией с небольшим кругом друзей. Координаты шифруются на устройстве сквозным шифрованием Olm/Megolm, а сервер хранит только шифротекст последнего пакета. Без номера телефона, email и истории перемещений. Ранняя разработка: пользоваться пока нельзя.

`Rust` · `Swift` · `SwiftUI` · `Kotlin` · `PostgreSQL`

### [Data Expedition](https://github.com/realfamousbae/data-expedition)

Плагин и навык для Claude Code для глубокого расследования. Он заставляет Claude работать как внимательный исследователь, а не как быстрый «суммаризатор»: анализирует репозитории, ищет в вебе по первоисточникам и проверяет утверждения, прежде чем написать отчёт с доказательствами. Рассчитан на модели уровня Claude Opus и Fable.

`Claude Code plugin` · `Python` · `Markdown`

### [RFB Jukebox](https://github.com/realfamousbae/drg-rfb-jukebox-music)

Мод для Deep Rock Galactic: все песни джукбокса в баре Space Rig заменены на 39 собственных треков. В паке только аудио, работает на клиенте, а каждый трек подогнан под точную длительность, которую игра отводит слоту.

`Python` · `PowerShell` · `Unreal Engine 4.27`

→ [Релизы](https://github.com/realfamousbae/drg-rfb-jukebox-music/releases)
